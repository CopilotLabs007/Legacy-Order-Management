# App-Modernization
App Modernization using Java/.Net

## Video Files

Video demonstrations are stored using Git LFS due to their large file size. You can access them through:

- **Direct download**: Use `git lfs pull` to download all LFS files
- **Web access**: View files directly in the repository at [https://github.com/im-sandbox-venkatpinfomagnus/App-Modernization.git](https://github.com/im-sandbox-venkatpinfomagnus/App-Modernization)

### Git LFS Setup

If you haven't set up Git LFS yet:

```bash
git lfs install
git lfs track "*.mp4"
git add .gitattributes
git add *.mp4
git commit -m "Add .mp4 files to Git LFS"
git push
```
